# 地区安全资源包协议 v1

状态：P0 冻结候选；尚无任何地区包获准随正式版本发布。

## 目的

地区安全资源包只承载经过人工核验的静态求助信息。它不承载安抚话术，不由模型生成，也不允许圆圆猜测电话号码、机构名称或服务时间。

只有同时满足以下条件的包才能进入 `Ready`：

- JSON 可解析且不超过 64 KiB；
- `schema_version` 为 `1`；
- 地区、语言、包标识和资源标识通过长度与字符集校验；
- 包含复核组织、复核时间、生效时间和过期时间；
- 从复核到过期不超过 180 天；
- 至少包含一项带电话号码的 `emergency_service`；
- 每项来源使用 HTTPS，资源标识不重复；
- 当前时间位于生效区间内。

缺失、格式非法、尚未生效或过期均关闭失败，进入固定的通用安全面板；不得继续显示旧号码，也不得从模型、搜索结果或历史缓存补全。

## Schema

```json
{
  "schema_version": 1,
  "pack_id": "reviewed-pack-id",
  "region": "region-code",
  "locale": "zh-CN",
  "reviewer_organization": "复核机构名称",
  "reviewed_at_unix_ms": 0,
  "valid_from_unix_ms": 0,
  "expires_at_unix_ms": 0,
  "resources": [
    {
      "resource_id": "resource-id",
      "kind": "emergency_service",
      "display_name": "经复核的展示名称",
      "phone_number": "+00 000",
      "source_label": "官方来源",
      "source_url": "https://official.example/resource",
      "availability_note": "经复核的服务时间或限制"
    }
  ]
}
```

`kind` 允许值：

- `emergency_service`
- `crisis_support`
- `medical_facility_guidance`
- `trusted_person_guidance`

示例中的机构、域名和号码均为占位符，不能作为真实资源发布。

## 通用降级

通用面板只允许固定系统文案，表达以下四种现实世界行动：

1. 联系所在地紧急服务；
2. 前往最近的急诊或医疗机构；
3. 联系信任的人；
4. 手动选择地区。

通用面板不显示电话号码，不声称圆圆能够提供危机干预，也不让用户继续停留在普通安抚动画中。

## 签发与更新流程

1. 内容负责人从当地官方来源建立候选包并保留来源快照；
2. 地区专业复核人核对号码、服务对象、服务时间、语言和适用范围；
3. 发布负责人确认复核身份、有效期和目标地区；
4. 构建时进行 Schema 校验，运行时再次校验时间；
5. 到期前重新复核并签发新包，不能只延长时间字段；
6. 撤销时立即删除对应包，使客户端进入通用降级。

## 仍未完成的发布证据

- 没有真实地区资源包；
- 没有职业健康或心理健康专业人员签字；
- 没有包签名、撤销清单和更新通道；
- 没有离线、系统时间异常和跨时区的完整发布矩阵；
- 没有真实用户对通用面板可理解性的测试。

因此，本协议实现只证明“不会猜号码”和“缺失即降级”的工程边界，不代表完整 Support Box 已具备发布资格。
