# 返回原任务工具门禁 v1

状态：P1-E07安全基础实现契约  
日期：2026-08-06  
实现：`yuanyuan-protocol`、稳定核心`return_action_registry`

## 1. 目标

本契约只解决“外部任务建议返回时，圆圆如何不把不可信字符串变成系统动作”。它不承诺Codex或Claude Code已经提供稳定返回能力，也不授权Hook、模型或任务终态自行打开任何程序。

## 2. 注册边界

- 注册表编译进稳定核心，不能由Hook、模型、Provider或普通配置扩展。
- v1只识别内置Codex与Claude Code连接器族的精确`open.task`动作。
- 完整`connector_id`必须带合法随机UUID后缀，`source_instance`必须是独立合法UUID，协议`source`必须与连接器实现严格对应。
- 历史固定身份、第三方命名空间、来源错配和未知动作全部拒绝。
- `target`不是URI或路径，只能是1—128字节、由ASCII字母、数字、`-`和`_`组成的不透明标识；规范化前后必须完全相同。

## 3. 两阶段校验

第一阶段发生在未来正式入口准备渲染之前：稳定核心从已认证任务记录取得私有动作，完成注册与目标校验后生成随机UUID凭证。凭证最长有效2分钟，进程内最多保存64个，过期项在签发前清除；前端只得到凭证、脱敏来源和过期时间，不得到目标。

第二阶段只能由明确用户点击触发：稳定核心先一次性移除凭证，再用当前注册表复核完整身份、来源、动作、目标和域分隔摘要。凭证无效或已重放时不执行任何动作；过期、注册撤销、内容篡改或处理器不可用时只返回固定任务守望台降级决策。

## 4. 当前处理器边界

两个注册项当前都绑定`SourceTaskUnavailable`，原因是正式来源工具的窗口定位、版本兼容、签名身份、锁屏行为和无障碍体验尚未完成验收。因此当前有效凭证也不会打开Codex、Claude Code、URI、文件或可执行程序。

模块故意没有注册Tauri命令，也没有正式前端按钮。后续每增加一个真实处理器，必须同时提供来源版本能力证据、固定可执行身份/Windows窗口策略、无Shell证明、锁屏测试、焦点行为测试和本威胁模型T11回归。

## 5. 隐私与审计

- 原始任务目标仅留在稳定核心进程内的短时待处理项中，不进入WebView。
- 关联审计使用带域分隔的SHA-256前16个十六进制字符，不记录原始目标、标题、正文、工作区或路径。
- 任务摘要只用于内部安全降级关联，当前没有暴露给前端。

## 6. 自动化证据

单元测试覆盖两个正式连接器族、历史身份、来源错配、未知动作、空/非法目标、URI、文件、UNC、命令、PowerShell、脚本式文本、路径穿越、控制字符、非ASCII、首尾空白、2分钟过期、一次性消费、注册撤销、待处理内容篡改和64项容量上限。

这些测试证明门禁默认关闭失败，不代表真实外部返回已经可用。
