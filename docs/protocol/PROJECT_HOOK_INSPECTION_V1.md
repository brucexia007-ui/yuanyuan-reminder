# 圆圆项目级 Hook 只读检查协议 v1

状态：P0 Windows只读产品入口与原生目录选择器已实现，真实Hook写入仍关闭  
日期：2026-08-05  
实现：`src-tauri/src/connector_project_inspection.rs`

## 目标与非目标

本协议允许用户对自己刚刚明确选择的一个项目目录，授权圆圆进行一次项目级 Hook 配置检查。检查同时理解用户级与项目级 Hook 的叠加关系，但不读取项目任务、代码、对话、Git、环境文件或任意递归内容，不启动 Codex/Claude Code，不修改配置，也不持久化项目选择。

任务面板现在只在来源工具双因子校验通过、随机连接器实例仍处于活动授权时显示“选择项目进行只读检查”。Tauri command只接受连接器身份，从Rust侧打开官方原生目录选择器；Web页面、命令参数、模型输出、近期任务、进程列表和历史记录都不能传入路径或替用户选择项目。原生选择结果在同一Rust模块内立即密封为目录能力，路径不会返回Web页面。

## 授权契约

1. 入口只允许由`panel`任务面板窗口调用；后端在打开选择器前先复核当前连接器授权和来源工具双因子。用户随后在以任务面板为父窗口的原生选择器中选择一个已存在的普通项目目录；相对路径、卷根目录、普通文件、最终组件为重解析点的目录和无法取得稳定 Windows 身份的目录全部拒绝。
2. 稳定核心打开目录句柄，绑定卷序列号与文件索引，形成不可序列化、不可从路径参数构造的内存目录能力。
3. 选择器关闭后再次验证当前随机连接器身份和来源工具双因子，防止选择期间升级、替换或撤权；预览仅签发一个两分钟、单次消费的随机令牌，全局最多保留16项等待确认。
4. 授权预览只说明可能读取用户级与所选项目级 Hook 配置，并明确任务数据读取、来源进程执行、配置写入、来源任务行为改变、路径返回和选择持久化均为否。
5. 确认只接收令牌。令牌不携带路径，返回值也不包含路径、目录名、连接器身份、凭据引用或配置原文。
6. 确认后先消费令牌，再重新验证连接器授权、来源工具双因子、当前预期圆圆 handler 和项目目录身份。任一材料变化都停止，不回退到旧授权或同名新目录。用户点击取消时令牌立即销毁；异常关闭时令牌最多两分钟后自动失效。

## 固定读取集合

检查不递归，只允许下列固定相对位置：

| 工具 | 用户级来源 | 所选项目级来源 |
| --- | --- | --- |
| Codex | 官方用户根目录的`hooks.json`、`config.toml` | `.codex/hooks.json`、`.codex/config.toml` |
| Claude Code | 官方用户根目录的`settings.json` | `.claude/settings.json`、`.claude/settings.local.json` |

每个候选文件必须是最大64 KiB的普通文件。打开后再次验证文件句柄身份与重解析点属性。项目根目录句柄在整个检查期间保持打开；项目配置子目录无论起初存在或缺失，结束前都再次确认状态和身份未变。根目录或配置子目录在读取过程中被重命名、替换或转为重解析点时，检查立即失效。

## 所有权与结果

所有成功读取的用户级和项目级来源在一次多来源预览中解析：

- 普通用户 Hook 可以同时存在于用户层和项目层，不形成虚假冲突；
- 圆圆拥有的 handler 只允许位于冻结的首选用户级来源；若出现在项目层或其他非首选来源，返回`owned_outside_preferred_source`并要求人工复核；
- 解析失败、双表示、重复所有权或首选来源冲突继续使用既有固定冲突枚举；
- 缺少项目配置仍属于一次完成的目录检查，项目配置读取数为0；
- 文件不安全或越界时返回固定人工复核结果或固定错误，不返回文件名、路径或错误正文。

结果只包含固定状态、脱敏多来源预览、用户/项目配置文件计数和安全事实。`projectDirectoryChecked`表示已检查所选范围，`projectConfigurationRead`只在实际读取至少一个项目配置文件时为真；二者不得混用。

## 当前证据与发布门

自动测试覆盖Codex/Claude固定来源、缺失配置、用户层/项目层共存、圆圆项目层所有权冲突、超大文件、目录伪装文件、相对路径/卷根/普通文件/重解析目录拒绝、根目录同名替换、读取中配置子目录替换、令牌取消/过期/重放/容量、来源工具专属第二因子和隐私门，以及授权预览、选择器响应和检查结果不含路径、命令、连接器身份或凭据材料。前端DOM测试覆盖原生选择请求、脱敏确认、单次确认和结果显示，令牌不进入可见文本。

仍未完成的发布门包括：Claude历史/后续版本、arm64实体文件与签名轮换矩阵，真实Codex/Claude安装形态复核、完整具备特权的祖先重解析点矩阵、真实Tauri窗口与无障碍验收、签名Bridge及安装升级/回退验证。当前入口只能做用户明确触发的零写入检查；这些门完成前不配置真实Hook，也不把项目目录选择持久化为自动观察范围。
