# 脱敏诊断快照 v1

状态：P0 工程格式；已接入用户主动预览、独立敏感扫描和 Windows 本机“另存为”，尚未接入客服发送流程，也不会自动上传。

## 目的

诊断快照只回答“组件是否存在、协议版本、AI运行状态、发生过哪类固定错误、队列有多大”。它不是日志归档、任务导出、会话记录或备份。

Schema 只有以下字段：

- `schema_version`；
- `generated_at_unix_ms`；
- 只允许安全字符且不超过32字节的 `core_version`；
- 任务事件协议和控制协议版本；
- 固定枚举 `ai_status`；
- 固定枚举诊断码及累计次数；
- 待处理文件数、字节数和隔离文件数。

格式没有任务标题、任务ID、工作区、绝对路径、用户名、提示词、代码、工具输入输出、Provider载荷、凭据、倾诉或支持偏好的字段。调用方不能用“附加备注”绕过这一限制；未知字段在反序列化时拒绝。

## 容量与文件边界

- 单份序列化上限：64 KiB；
- 旧的应用自有诊断目录最多5份；达到上限后拒绝新写入，不静默删除旧证据；当前用户“另存为”流程不在该目录创建副本；
- 应用自有快照文件名只由固定前缀、Schema版本和毫秒时间组成；用户导出提供固定默认名，并允许在原生窗口中修改；
- 用户导出只接受 Windows 本机普通驱动器上的绝对`.json`路径；UNC、映射远程盘、缺失父目录、重解析祖先和非普通父目录关闭失败；
- 已存在的目标文件永不覆盖；先在用户选择的同一目录创建唯一临时文件，应用当前用户DACL并同步落盘，复读扫描通过后以无替换方式改名；
- 最终文件再次应用当前用户DACL、复读并重新扫描；任一步失败只清理由本次调用创建的精确临时文件；
- 根路径必须是普通目录，文件、符号链接或匹配名称的非普通文件关闭失败；
- Windows 下目录、临时文件和最终文件均应用当前用户专用的受保护 DACL；
- 用户选择的最终文件不属于应用自有诊断目录，应用内“清除本地诊断数据”不会删除它。

## 诊断码

当前只允许 Bridge v1 的十种固定码：输入过大、JSON非法、协议非法、接收端不可用、队列满、超时、接收端拒绝、认证失败、认证存储不可用和重放拒绝。错误正文不进入快照。

## 用户流程边界

当前设置页只有在检测到可选 AI 二进制时提供生成入口。用户第一次点击只执行只读预览，不写文件；预览展示唯一 JSON 文件、Schema版本、预计字节数、真实队列规模、固定错误类别/总次数、独立敏感扫描版本与4项检查结论，并明确列出不包含的敏感类别、不会创建应用内副本及“不会自动上传”。后端读取真实 AI 监督状态，并以只读方式统计既有 Bridge 暂存目录；统计不会创建目录、解析事件、重放或清理载荷。

只有第二次点击“选择保存位置”才打开 Windows 原生保存窗口。取消选择不会创建文件并保持预览可见；确认后，后端会对预览序列化字节、临时文件复读内容和最终文件复读内容分别执行同一独立扫描。扫描器只接受可重新序列化为完全相同规范字节的类型化v1 JSON，拒绝未知字段、非规范编码、路径/用户名标记、凭据/令牌/私钥特征和超过64 KiB的内容。前端只收到状态、文件名、字节数和扫描结论，不接收绝对路径；失败统一返回不含内部路径的固定提示。

Bridge 对失败采用独立的本地 SQLite v1 计数表，只接受十种固定错误码和正整数，不接受错误正文。记录位于既有3秒总看门狗内；数据库锁冲突使用零等待并直接放弃本次计数，外层超时计数另有100毫秒上限。计数失败不改变 Hook 的静默 fail-open 退出契约。诊断导出只读打开既有计数库；目录或数据库不存在时返回空计数且不创建存储，未知码、非正计数、文件或链接会关闭失败。

若以后接入客服或问题跟踪系统，发送前仍必须重新展示固定文件清单、Schema版本、大小和独立敏感扫描结论，并再次允许用户决定是否发送；当前本机保存授权不能被复用为上传授权。若后续模块需要更多信息，应增加经评审的类型化字段并升级Schema，不能加入通用字符串日志数组。

设置页提供二次确认的“清除本地诊断数据”。清理前先校验全部目标，只删除数字时间戳命名的v1快照和固定计数数据库/辅助文件；诊断目录、任务暂存队列、提醒数据库、备份和无关文件均保留。任一匹配目标是目录、链接或其他非普通文件时，在删除任何文件前整体拒绝。AI二进制移除后，只要诊断残留仍存在，清理入口继续显示。

当前NSIS仍沿用用户数据默认保留策略，不宣称卸载程序会自动删除诊断数据。完整卸载前，用户可先在设置页主动清理；未来若在卸载器增加删除选项，必须默认保留并逐项说明诊断、任务、记忆与提醒数据的不同范围。
