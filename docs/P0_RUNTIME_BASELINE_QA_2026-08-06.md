# P0隔离运行性能烟测（2026-08-06）

## 结论

已建立不接触正式用户数据的真实Tauri运行采样器，并完成一次60秒AI关闭烟测。进程受控退出、正式目录零写入、AI子进程为0、Application Error为0、隔离目录安全删除，烟测通过。

本记录只证明采样链、短时启动和短时稳态资源事实。它不是24小时常驻、系统睡眠恢复、提醒延迟、正式默认二进制、冷机或干净机性能结论，不能用于关闭P0-003完整门禁。

## 运行边界

- 使用非默认`runtime-qa`编译功能，默认正式主程序和NSIS不包含该功能；
- 使用独立应用标识、带精确标记的专用根目录、独立提醒/AI数据和与正式用户隔离的共享WebView目录；
- `baseline-ai-off`配置只显示宠物窗口，面板保持隐藏，AI数据库不存在且不启动`yuanyuan-ai.exe`；
- 进程启动后按配置在30秒至72小时内受控退出；未知配置、越界时长或不安全目录关闭失败；
- 采样结束仅在父目录、固定前缀和标记内容全部精确匹配时递归删除隔离根；
- 当前采样以10秒预热排除WebView创建期，CPU按主程序和全部后代进程逐PID计算相邻样本增量；新生进程首帧不把历史累计CPU记入当前区间；
- CPU按24个逻辑处理器归一化；工作集和私有内存为进程树逐进程求和，工作集会重复计算进程间共享页面，不能与单进程工作集直接比较。

## 采样器完成条件

烟测只有同时满足以下条件才返回0：

- 圆圆在30秒内创建可见窗口；
- 有至少一个稳态样本；
- 到时通过应用自身退出路径返回0；
- 正式用户目录新增写入为0；
- 没有AI子进程；
- Application Error查询可用且结果为0；
- 隔离根通过精确所有权验证后删除。

若事件日志不可查询、进程提前退出、隔离目录无法安全删除或任何上述条件失败，报告保留事实并以退出码2阻断。

正式二进制边界现扫描17个非生产专用标记：原有8个运行验收环境变量、配置值、标记文件名和夹具名，3个数据库迁移验收程序/临时目录/证据声明，3个任务保留负载验收程序/配置/临时目录标记，1个任务失败动作运行配置，1个Support Sort精确正文金丝雀，以及1个PID复用压力执行器名。任一标记出现在默认release主程序即阻断发布预检。
