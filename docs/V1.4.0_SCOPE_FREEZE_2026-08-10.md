# 圆圆提醒 v1.4.0 范围冻结

状态：工程候选已冻结，正式发布仍为 NO-GO  
冻结日期：2026-08-10  
基线：v1.3.2 之后的当前 v1.4.0 工作树

## 1. 冻结目的

本文件把 v1.4.0 的离线稳定版交付范围与后续智能陪伴 P0 原型明确分开。冻结后，v1.4.0 只接受发布阻断修复、回归修复、证据修正和不改变外部行为的维护；新增智能能力继续在独立质量门下推进，不得因为源码已经存在就进入安装包或对外宣称可用。

## 2. v1.4.0 交付范围

v1.4.0 正式候选包含：

- 完全离线的提醒、喝水、活动、专注、休息和宠物互动核心；
- 今日、设置、专注和互动模块的故障隔离与局部重试；
- 普通提醒的创建、编辑、启停、软删除和历史保留；
- 一次性、间隔、每日及自选星期提醒，含 5/10/30/60 分钟稍后提醒；
- 错过提醒策略、系统提醒保护和确定性的提醒优先级；
- 每日自动备份、手动备份、完整性校验、安全恢复和 14 份自动备份保留；
- 非语言宠物反馈、减少动态、道具标签和用户主动发起的基础陪伴；
- Windows x64 当前用户 NSIS 安装包、四份许可证材料和离线运行边界。

正式运行不得依赖 Codex、Claude Code、Node.js、Rust、Python、账户、遥测、云服务或任何 AI Provider。

## 3. 明确不进入 v1.4.0 安装包的能力

以下源码、协议、夹具或开发实验台属于 P0/P1 技术验证，不构成 v1.4.0 用户承诺：

- `YuanyuanBridge.exe`、`YuanyuanAI.exe` 和所有 QA/诊断夹具；
- 真实 Codex/Claude Code Hook 写入、撤销和任务事件接入；
- 返回原任务工具的正式按钮或外部处理器；
- 真实本地或云端 Provider、通用模型对话和自动工具执行；
- 正式记忆中心、加密 AI 备份和便携导出；
- 完整 Support Box、地区危机资源和未经专业复核的安抚路径；
- 开发环境中的连接器、表达、数据边界和断开/恢复实验台。

上述能力必须继续保持功能门关闭、无正式命令、无安装声明或仅提供脱敏只读状态。任何开放都需要单独的范围变更、威胁模型复核和对应发布门。

## 5. 仍然阻断正式发布的项目

正式发布前至少必须关闭：

- 发布主体、渠道、精确发布者 Subject、代码签名和 RFC 3161 时间戳；
- SmartScreen、Defender 可用环境及两款不同第三方安全产品的候选绑定人工验收；
- 许可证、素材权利和发布候选的具名人工复核；
- 100%/125%/150%/200% DPI、文本缩放、高对比度、减少动态、全键盘和 Narrator 人工矩阵；
- 真实 v1.3.2 用户数据库迁移、默认安装路径控制面板注册、系统重启、物理中断和安全回退；
- 24 小时正向运行以及真实睡眠/唤醒、锁屏/解锁事件；
- WS0、WS1、WS2、WS8 的具名负责人和可接手者。

发布预检中任何 `pending` 或 `failed` 项都必须保持 `readyForRelease=false`；不得用自动化、AI 签字、裸布尔值或未绑定当前候选的历史证据代替人工与实机门。

## 6. 冻结后的变更规则

- D0：文档修正、测试增强、不改变外部行为的重构，可在相关自动化通过后合入；
- D1：提醒契约、数据字段、UI 语义或默认值变化，需要兼容测试和变更记录；
- D2/D3：权限、协议、网络、凭据、数据库归属、签名、安装和用户安全变化，必须先更新 ADR/威胁模型并由责任人联签；
- 任何 P0/P1 能力进入正式安装包，都必须新建版本范围决定，不得修改本文件将其追认为 v1.4.0 已交付能力。
