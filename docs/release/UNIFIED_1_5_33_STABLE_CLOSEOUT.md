# 圆圆 1.5.33 与饺饺宠物包稳定版收尾

当前状态：源码准备中；`COMMUNITY_STABLE_ACCEPTANCE_V1.json` 仍为 `pending`。本文件不是验收通过或发布授权。

## 身份和候选冻结

- 主程序固定为 `圆圆提醒`、`com.yuanyuan.reminder`，沿用原主库和学习库路径。圆圆图集、图标、服装、热身动作和专注静止保持原样。饺饺仅作为独立 `.yuanyuan-pet` 包交付。
- 在独立 `release/unified-1.5.33` 分支整合 `main`。候选必须来自干净提交；源码、脚本或许可有任何后续修改，都要重新冻结提交、重新构建并重做与产物相关的验收。
- 执行 `npm.cmd run verify`、`cargo test --manifest-path src-tauri/Cargo.toml --locked`、`npm.cmd run tauri build`、发布边界与许可检查。用 `npm.cmd run release:community:candidate:freeze -- --pet-pack <原始饺饺包路径>` 保存安装器、便携程序、宠物包的原始字节和 SHA-256。冻结清单先标为 `PENDING`。
- 饺饺包的固定哈希、来源提交和包内许可哈希见 [`JIAOJIAO_PACKAGE_SOURCE.json`](../pet-packs/JIAOJIAO_PACKAGE_SOURCE.json)。原许可逐字节归档在 [`JIAOJIAO_STANDALONE_ASSETS_LICENSE.md`](../pet-packs/JIAOJIAO_STANDALONE_ASSETS_LICENSE.md)。该许可描述来源独立程序的素材路径；统一主程序的同名素材路径仍属于圆圆。宠物包内的 `LICENSE.txt` 与归档原许可哈希一致。

## 最终候选的必需验收

1. 两只宠物在真实鼠标下分别验证猫条与逗猫棒的移入、按下、跨元素拖动、停留、释放，记录位置、帧推进和结束恢复。100%、125%、150% 各验证布局与点击范围；两只宠物工作专注各观察至少 30 秒，并检查关闭动画。
2. 在隔离 Windows 环境安装最终安装器，验证提醒送达、延后 30 分钟、漏提醒策略、隐藏恢复、面板拖动、自动备份与恢复、重启和卸载默认保留数据；复跑学习、宠物包损坏恢复和 1.5.27 升级回退关键路径。
3. 对同一干净候选完成至少 24 小时观察和 20 小时有效覆盖，包含睡眠恢复、锁定解锁、受控退出，应用错误为零；完成真实 Tauri 20,000 张卡导入、1,000 次答题、取消、分页、增长与恢复。
4. 使用来源可核验的 1.3.2 历史数据副本验证保留、备份恢复及迁移失败回滚。找不到真实历史副本时保持阻塞，不以合成数据替代。
5. 由用户指定的实际复核人核对最终报告并署名。不要代填人工结论。所有问题清零后才能把验收文件改为 `accepted`。

冻结提交之后，稳定通道晋级只允许更改 `product-version.json` 和 `docs/release/COMMUNITY_STABLE_ACCEPTANCE_V1.json`。若源码或工具再改动，新的提交必须重新作为候选接受完整验收。

## 已验收字节与 GitHub 草稿

验收后在干净稳定通道提交上运行 `npm.cmd run release:community:candidate:promote -- --candidate-dir <冻结候选目录>`。晋级工具要求人工验收通过，核对源码祖先关系和仅有的两项晋级变更，重新读取三项原始候选文件与许可并验证哈希，不重建安装器。`npm.cmd run release:community:prepare -- --tag v1.5.33 --commit <稳定提交> --accepted-dir <晋级目录> --output-dir release/staged-v1.5.33` 生成待上传附件、公开哈希清单、来源说明和发布说明。缺少证据、版本不一致或字节不同都会停止。

推送稳定标签后的工作流只创建 GitHub Release **草稿**，不会自动附加重建文件，也不会公开。取得后续授权后才可推送、建立 PR、合并、上传已验收附件和公开发布。上传前后均须核对每个远端附件的哈希；若草稿已有同名附件，先查明来源，不覆盖。公开材料只放脱敏摘要；原始用户数据、完整备份与私人照片仅本地保留。

饺饺原许可限定素材用途。公开附加宠物包之前，须由相应权利人确认本次公开分发在授权范围内，并在发布记录中保存确认结果。未获确认时草稿保持未公开。

## 用户主机采用与回退

用户主机的正式安装另需授权。安装前确认实际版本和数据位置，正常退出应用，对旧程序、旧安装器、主库、学习库、WAL/SHM、宠物包、选择配置和设置做带时间戳的完整备份，记录逐文件 SHA-256，并在副本上检查数据库完整性。只安装已验收哈希对应的安装器，在新增使用记录之前核对旧卡片、排程、历史和设置，再验证两只宠物、提醒、学习、专注、退出和重启。

失败时保留升级后现场，恢复**旧程序与升级前完整数据目录**。数据库迁移后的回退不能只降级程序，也不能覆盖唯一备份。
