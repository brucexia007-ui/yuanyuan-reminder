# 1.5.33 V2 验收豁免决定记录

用户在本任务中明确要求实施 V2 稳定验收，并限定三项豁免：运行观察中的系统睡眠恢复、锁屏解锁，以及缺少真实 1.3.2 用户历史数据。除此之外的运行时长、有效覆盖、零应用错误、原生交互、安装器、学习与升级回退检查仍须通过。

原始运行报告必须保留 `passed=false`，两项事件必须保留 `observed=false`。V2 只有在原始失败代码恰为这两项时才可接受运行观察。真实 1.3.2 用户历史数据继续标为未验证；官方 1.3.2 程序生成的合成数据、真实 1.5.27 安装器升级与配套回退是必需的替代测试，但不证明真实历史记录兼容。

本文件记录用户对豁免范围的决定，不是人工验收署名，也不是饺饺素材公开许可。最终验收文件须绑定本文件 SHA-256、冻结候选提交和各证据 SHA-256；实际人工复核与素材许可另行取得。
