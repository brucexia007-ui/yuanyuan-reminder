# Microsoft Store 截图采集要求

这里最终应放置与正式 Store 候选绑定的四张真实 Windows 桌面截图：

1. `01-today.png`：今日喝水进度、待办事项和桌面宠物；
2. `02-focus.png`：专注与离屏休息；
3. `03-care.png`：照料与互动；
4. `04-settings.png`：提醒、自启动、通知和本地备份设置。

每张图片必须满足：

- 来自与 `msix-store-candidate-report.json` 相同的候选，不使用设计稿、浏览器模拟或生成式图片冒充真实界面；
- 使用合成测试数据，截图前确认没有真实姓名、提醒内容、路径、账号、通知、桌面文件或其他个人信息；
- PNG、横向、至少 1366×768、单文件不超过 50 MB；建议 1920×1080；
- 不额外叠加营销文案、徽标、设备边框或不属于应用的界面；
- 关键界面放在画面上方三分之二，避免 Store 覆盖层遮挡；
- 在一次性 Windows 11 虚拟机或专用测试账户中采集，并在提交材料中记录候选 SHA-256、图片 SHA-256、尺寸、采集人和时间。

仓库现有 `docs/images/*.jpg` 为 README 演示图，尺寸为 1280×720 且格式为 JPG，不满足 Store 桌面截图要求，不能直接上传或简单放大后冒充正式候选截图。
