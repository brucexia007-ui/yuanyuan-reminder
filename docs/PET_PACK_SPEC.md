# 圆圆提醒宠物包规范

本文定义圆圆提醒 `1.3.x` 使用的宠物素材格式。目标不是让界面“轮播不同照片”，而是让同一只宠物在所有动作里保持身份一致并形成连贯动画。

## 1. 公共几何规则

- 每格：`192 × 208` 像素；
- 每行：8 格，总宽 `1536` 像素；
- 背景：真正透明，透明区域隐藏 RGB 应清零；
- 主体：完整身体不得跨格、裁切或接触外边缘；
- 视觉身份：毛色、脸型、眼睛、鼻子、耳朵、花纹、四肢比例和体态必须保持一致；
- 禁止：场景背景、文字、对话框、投影、光晕、速度线、网格、动作编号和游离特效。

## 2. 标准图集 `spritesheet.webp`

尺寸：`1536 × 2288`，即 8 列 × 11 行。前 9 行是标准动作，后 2 行是 16 个顺时针注视方向。

| 行 | 动作 |
| --- | --- |
| 0 | 安静待机、呼吸和眨眼 |
| 1 | 向屏幕右侧移动 |
| 2 | 向屏幕左侧移动 |
| 3 | 抬爪打招呼 |
| 4 | 跳跃；活动提醒复用这一行形成连续蹦跳 |
| 5 | 失败或失落反馈 |
| 6 | 等待用户处理或确认 |
| 7 | 正在处理任务的专注动作，不是向前跑 |
| 8 | 检查或回顾动作 |
| 9 | 注视 000°、022.5°、045°、067.5°、090°、112.5°、135°、157.5° |
| 10 | 注视 180°、202.5°、225°、247.5°、270°、292.5°、315°、337.5° |

方向使用屏幕坐标：000° 向上，090° 向右，180° 向下，270° 向左。四个主方向必须一眼可辨，不能只靠极小的瞳孔移动。

## 3. 睡眠图集 `sleep-atlas.webp`

尺寸：`1536 × 624`，8 列 × 3 行。

| 行 | 动作 |
| --- | --- |
| 0 | 从清醒进入睡姿 |
| 1 | 熟睡呼吸循环 |
| 2 | 从睡姿醒来 |

进入睡眠和醒来应是可逆的姿态变化；循环帧需保持身体基线稳定。

## 4. 生活与互动图集 `life-atlas.webp`

尺寸：`1536 × 4368`，8 列 × 21 行。

| 行 | 动作 |
| --- | --- |
| 0 | 舔爪或洗脸 |
| 1 | 舔胸口 |
| 2 | 舔身体侧面 |
| 3 | 伸懒腰 |
| 4 | 打哈欠 |
| 5 | 喵叫 |
| 6 | 翻肚皮躺下与反向起身 |
| 7 | 专注状态下安静坐卧 |
| 8 | 吃猫粮 |
| 9 | 喝水 |
| 10 | 追随猫条高度和方向 |
| 11 | 基础逗猫动作 |
| 12 | 用头蹭鼠标 |
| 13 | 左右爪扒拉球 |
| 14 | 向目标伸爪 |
| 15 | 抓挠逗猫棒 |
| 16 | 收爪回到坐姿 |
| 17 | 低头叼起球 |
| 18 | 叼球走回 |
| 19 | 放下球 |
| 20 | 双爪拍“屏幕玻璃”的强提醒动作 |

每一行应作为一个连续的 8 帧动作家族生成。不要从不同风格图片中各裁一帧拼接，也不要用程序扭曲一张静态图片伪造动作。

## 5. 清单文件

运行时清单位于 `public/assets/pet/pet-manifest.json`，定义图集路径、格子尺寸、动作所用行、帧顺序、每帧时长和循环起点。

替换宠物时，优先保留动作名称和调用语义，只在动作实际需要时调整帧序及持续时间。完成后必须执行：

```powershell
npm.cmd run pet:validate
npm.cmd run check
```

## 6. 最低验收条件

- 三张图集尺寸和透明通道正确；
- 标准图集的 8×11 格全部满足结构要求；
- 左右移动方向正确，步态不倒放；
- 16 个注视方向按顺时针形成自然连续环；
- 四个主方向明确，左右不会相反；
- 所有动作保持同一宠物身份；
- 动画没有尺寸跳变、基线跳动、裁切、残影或背景色边；
- `npm.cmd run verify` 和 Windows 正式构建通过。

## 7. 许可要求

只使用你拥有或获得明确授权的宠物照片和生成素材。不要把第三方社交账号里的宠物照片、图库图片或不明来源模型输出直接提交到公开仓库。每个宠物分支应附带自己的素材许可说明。
