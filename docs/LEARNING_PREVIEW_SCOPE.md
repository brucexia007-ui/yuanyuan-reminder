# Learning Preview 实验范围

状态：功能开发已形成可运行预览；默认关闭；不构成发布承诺<br>
产品合同：`docs/YUANYUAN_KAOYAN_ENGLISH_LEARNING_FINAL_PLAN.md`<br>
稳定基线：圆圆提醒 v1.4.0<br>
更新日期：2026-08-10

## 目标

在不改变 v1.4 提醒核心和默认安装边界的前提下，验证一个离线、导入优先的考研英语碎片复习模块。圆圆只负责递送和陪伴，学习文字属于卡片工具。

## 当前实现快照

以下能力已经在 `learning` Cargo feature 与 `VITE_FEATURE_LEARNING=1` 前端构建门后实现：

- 独立 `yuanyuan-learning.sqlite3`、schema v2、外键、WAL、2 秒 `busy_timeout`、事务迁移和完整性检查；
- 通用 UTF-8 CSV 与圆圆原生版本化 JSON 的 preview/confirm 两阶段导入；
- 用户主动开始的 1/3/5 张学习会话、英文识义、翻面、词族提示和“忘了/模糊/记得”三档自评；
- FSRS-6 本地调度，固定 0.9 目标保持率，不训练个人参数；
- 学习首页、数据来源/许可展示、完整 JSON 与两类 CSV 导出、清空进度和彻底删除；
- 可选的阶段 2A 自动模式，仅由专注结束触发；默认关闭，无到期卡或系统状态不明确时关闭失败；
- 主库 schema v12 的无内容注意力 claim/补偿记录，不在主库保存单词、卡片、词包或释义；
- 合上的非语言宠物邀请卡，支持打开、忽略和“今天不再邀请”；高优先级提醒可抢占并清理学习道具；
- 默认关闭与开启构建分别有边界验证，学习页面保持独立代码分包。

实现状态与未关闭门详见 `docs/learning/IMPLEMENTATION_STATUS.md` 和 `docs/learning/QA_MATRIX.md`。

## 默认关闭合同

默认构建必须同时满足：

- Cargo `learning` feature 未启用；
- 前端学习构建门未启用；
- `learning.available=false`；
- 不注册学习命令，不打开或创建学习数据库；
- 不打包学习页面、演示数据或任何学习内容；
- `npm.cmd run learning-off:verify` 通过；
- 喝水、活动、普通提醒、专注、任务守望、备份和宠物行为保持现有合同。

## 第一版能力边界

进入预览范围：

1. 用户导入自己有权使用的学习内容；
2. 完全手动模式，以及用户明确开启的“仅专注结束”低频邀请；
3. 英文识义、三档自评、FSRS 间隔复习、每卡即时保存与随时退出；
4. 本地来源/许可说明、数据导出、清空进度和彻底删除；
5. 无内容的本地学习指标与防打扰漏斗。

明确排除：

- 修改 v1.4.0 版本号或把实验能力追认为已交付；
- 未授权考研词包、自动抓取词库、例句、音频、拼写、听说、聊天或长课程；
- 账号、云同步、遥测、安装后网络访问和必需 AI；
- 直接兼容商业背词应用私有格式；
- 定时时段、短空闲推断、会议/演示期间邀请或错过后的补发；
- 用“相对稳定”宣称考试掌握或提分。

## 内容与发布边界

仓库当前不包含可发布的考研词包。浏览器演示词只存在于开发内存夹具，生产安装包不得携带。用户导入内容的权利由用户负责；产品不会上传或改标为官方内容。

Learning Preview 进入正式安装包前，必须另行关闭：

1. 内容来源、再分发权和具名语言质量确认；
2. FSRS 许可证/SBOM、第二来源向量、体积与冷启动增量；
3. Windows 100/125/150/200% DPI、Narrator、强制颜色、锁屏/演示/全屏和真实提醒竞态；
4. 提醒领取与呈现延迟、7 天防打扰漏斗和小样本用户研究；
5. 产品合同第 12 节的独立 Go/No-Go。

上述门未关闭时，可以继续在实验 feature 中验证，但不得默认开启或进入稳定版安装包。
