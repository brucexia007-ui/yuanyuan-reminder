# P0 安抚能力安全 Spike 与开发分解

日期：2026-08-04  
状态：三路径基础陪伴已进入正式运行时；完整 Support Box 仍被专业复核和真实地区资源阻断。

## 1. 本轮结论

安抚能力拆成两个可独立发布的层级：

| 层级 | 对用户开放的路径 | 依赖 | 当前结论 |
| --- | --- | --- | --- |
| 三路径基础陪伴集 | 只陪我一会、陪我动一动、先别管我 | 本地状态机、猫咪动作 | 已进入正式构建；仍需真实窗口与用户辨识验收，不宣称疗效 |
| 完整 Support Box | 上述三项 + 只听不记、缓一缓、理一理 | 专业复核、真实地区资源、Core 数据去向提示 | 继续关闭 |

完整六路径只有在 `professionalReviewPassed` 与 `regionalSafetyResourcesReady` 同时为真时才可见。任一条件为假都确定性裁剪为三路径，不允许用远程配置、模型判断或实验参数绕过。

## 2. 已实现的边界

### 2.1 用户主动触发和会话状态机

会话只能从用户主动靠近/打开开始，状态为：

`approach → choosing → active → optional_check_in → closed`

“先别管我”从活动状态直接关闭，不再追问；其他路径最多有一次可跳过的回看，不形成连续追踪或依赖性互动。

### 2.2 “只听不记”

倾诉正文只存在于前端会话对象的内存字符串中：

- 最大 16 KiB UTF-8；
- 拒绝 NUL 和双向控制字符；
- 不使用浏览器存储、数据库、日志、网络、后端命令或模型；
- 仅在对应活动状态可读；完成、关闭或新建会话后不可读；
- 应用崩溃后没有恢复来源，因此按产品语义丢弃。

这里的“清除”指断开应用层可达引用和禁止持久化，不承诺 JavaScript 运行时或操作系统内存的取证级清零。产品文案不得写成“物理不可恢复”。

### 2.3 支持偏好

AI 数据库当前 Schema 为 v4；v4仅增加任务摘要证据等级，不改变支持数据边界。只允许保存用户明确确认后的类型化偏好，不允许保存原始倾诉、原因或自由文本：

- 靠近距离：近、舒适、远；
- 受挫后的第一反应：安静陪伴、给出选择、展示证据；
- 避免方式：呼吸、倾听、活动、回看；
- 回看：不回看、一次。

偏好支持全局或项目作用域、查询、彻底删除、墓碑和旧备份恢复时的防复活。v2→v3 迁移保留旧记忆墓碑；建表冲突会完整回滚并保持 v2 可重试状态。基础三路径不依赖偏好库，AI 不可用时仍使用安全默认值。

### 2.4 地区安全资源

资源包 v1 已冻结大小、字段、复核时间、180 天最长复核周期、HTTPS 来源、必需紧急服务和号码格式。缺失、非法、未生效或过期全部进入无号码的固定通用面板。当前没有真实资源包，测试数据均为明确的虚构占位内容。

### 2.5 正式三路径基础陪伴

照料页已提供“陪陪我”入口，且只能由用户主动打开。正式运行时只向 Rust 稳定核心提交固定路径枚举和固定时长：

- 只陪我一会：2、5、10 分钟；
- 陪我动一动：1、3、5、10 分钟；
- 先别管我：5、15、30、60 分钟。

会话只保存在主进程内存，不创建数据库表，不写原因、情绪、自由文本、日志、备份或 AI 数据库；应用重启即结束。计时到点自动退出，也可由用户随时结束。喝水、到期工作事项和外部任务等待用户可以抢占；活动提醒、任务终态和后台守望不会打断本次陪伴。专注计时与基础陪伴互斥，进入专注或开始普通猫咪互动会结束本次陪伴。

三条路径都只使用固定猫咪动作和屏幕阅读器语义，不显示猫咪对白或情绪判断。其中“先别管我”使用独立退开动作，不触发回看、打卡或延长邀请。

## 4. 测试矩阵

必须至少覆盖：

- 两个质量门的四种组合都只产生预期路径集合；
- 未开放路径不能通过直接调用状态机进入；
- 敏感短语输入后，关闭、完成、崩溃和重启均无恢复入口；
- 源码和产物扫描不出现只听不记的持久化/网络 API；
- 未确认的偏好不写入，跨项目不串用，删除墓碑阻止旧备份复活；
- 资源包缺失、畸形、超大、重复、未来生效、过期、无紧急服务、非 HTTPS 均降级；
- Provider、AI 进程或数据库不可用时三路径基础陪伴仍可完成；
- “先别管我”不回看，“只陪我一会”不诱导延长互动；
- 减少动态、键盘、屏幕阅读器和小窗口模式保持等价语义。

## 5. 明确不做

- 不判断或诊断用户的心理状态；
- 不声称治疗、预防或降低心理疾病风险；
- 不自动识别情绪后强行介入；
- 不把互动时长、连续天数或回访率作为安抚成功指标；
- 不由 LLM 生成危机号码、医疗建议或资源包；
- 不把完整 Support Box 延期传播为 v2.0B Core 的发布阻断。

## 6. 当前发布判断

三路径基础陪伴集已进入正式构建，并完成首轮真实Tauri窗口、自动/手动结束和退开动作实拍；键盘、屏幕阅读器、多档DPI和目标用户辨识仍未通过，因此不宣称已经通过完整发布体验门。只听不记、支持偏好和资源包实现目前只构成 P0 工程证据；没有专业签字与真实地区包之前，完整名称、六路径入口、呼吸练习、倾诉收集、问题整理及“安抚有效”的任何产品表述均不得进入正式构建。
