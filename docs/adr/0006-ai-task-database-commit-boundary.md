# ADR-0006：AI任务数据库与确认提交边界

状态：Accepted for P0<br>
日期：2026-08-04<br>
对应实现：`src-tauri/crates/yuanyuan-ai`<br>
对应方案：最终设计13.2、开发方案P1-E01—E03

## 背景

任务守望事件来自外部Hook，可能重复、乱序、延迟或在接收端提交后丢失ACK。把这些写入现有`yuanyuan-reminder.sqlite3`会让外部事件风暴、迁移失败或数据库损坏影响喝水、专注和提醒等稳定核心，也违反三进程、双数据库故障域设计。

## 决策

- 独立`YuanyuanAI.exe`拥有`yuanyuan-ai.sqlite3`；提醒主程序不得直接迁移或写入该库；
- v1任务库包含`watched_tasks`、`task_events`和`task_event_nonces`，凭据正文仍只存在Windows Credential Manager；
- HMAC和时间窗在事务前验证；nonce登记、事件审计和当前任务更新在一个`BEGIN IMMEDIATE`事务中完成；
- 任一数据库写入失败时整个事务回滚，接收端不得ACK；
- 已经提交但ACK丢失的完全相同事件返回`AlreadyCommitted`并允许再次ACK；相同nonce绑定到不同事件时拒绝；
- 乱序和重复终态事件持久化为审计记录但不回退当前任务；非法转换持久化为`rejected_transition`且不改变当前任务；
- 任务身份键覆盖连接器、来源实例、来源、工作区、外部任务标识和任务标识，字段使用长度前缀后再计算SHA-256，避免简单拼接歧义。
- 当前任务摘要保存固定`evidence_level`；决定性状态只有权威证据才进入只读表达链，非权威结果投影为`unknown`，完整规则见`protocol/TASK_STATE_RESOLUTION_V1.md`。

## 当前证据

自动化测试覆盖首次原子提交、ACK丢失后的幂等重送、乱序事件不回退状态、认证失败零写入、事件表故障时nonce和任务同步回滚、启动暂存重放，以及真实安全管道上的“提交后ACK/无效事件无ACK”、连续事件、独立关闭管道唤醒和单实例锁。`SQLITE_FULL`注入证明满盘失败不会留下nonce、事件或任务半提交，解除页数限制后同一事件可重试；第二连接持有写锁时同样零写入，释放后恢复。只读句柄拒绝写入后可恢复可写，Windows独占文件占用期间打开失败并在释放后恢复。真实`yuanyuan-ai.exe`被强制终止后，已提交事件仍在原库中，新进程可以使用该库重新健康启动。工作区测试证明该库不依赖Tauri主程序状态。

数据库已增加 v2 记忆生命周期、v3 类型化安抚偏好和v4任务证据投影迁移。自动化测试证明 v1 任务数据升级后保持不变；v2 对象创建冲突会回滚全部迁移对象并保持 `user_version=1`；v3 建表冲突会保留完整 v2 数据和旧记忆墓碑并保持 `user_version=2`；v4为既有任务安全填入`unknown`而不解析旧事件正文，列冲突会保持完整v3数据库与`user_version=3`，修复后均可重试。记忆正文、FTS、关系、检索审计、偏好和墓碑删除同样使用独立立即事务。

任务事件保留策略当前冻结为普通进度7天、等待用户/终态/纠正证据90天、终态任务摘要180天、长期无更新非终态摘要365天。清理器每轮最多处理1,000条事件和250个任务，在一个立即事务中同步清理过期nonce；任一错误整体回滚，仍存任务的最新事件始终保留。详细规则见`protocol/TASK_EVENT_RETENTION_V1.md`。常驻AI服务在任务与控制管道均健康后才启动维护线程，5秒后执行首轮，此后每6小时低频重复；服务退出会通知并回收线程，单轮失败只丢弃无敏感内容的结果并保留下一轮机会。

全新且无用户表的AI数据库在任何迁移建表前冻结为SQLite `auto_vacuum=INCREMENTAL`；每个发生逻辑删除的维护周期随后逐页推进、最多回收256页，无进展立即停止。旧版本库、未知v0外部表和`auto_vacuum=none`数据库不执行隐式`VACUUM`或格式转换，避免升级时全库重写。固定一年等价负载表明，无增量回收时清理后仍有7,382个空闲页、数据库家族32,903,168 bytes；新策略在相同逻辑结果下回收全部7,382页并降至2,670,592 bytes。该合成结果仍不替代24/72小时、系统睡眠恢复和真实连接器负载校准，见`P0_TASK_RETENTION_LOAD_QA_2026-08-06.md`。

## 剩余门禁

- 历史发布数据库升级矩阵、损坏隔离、加密备份实现和保留期参数；
- 多客户端并发服务、长时间增长、真实系统睡眠恢复、保留期和增量回收周期校准；
- 既有`auto_vacuum=none`数据库是否提供显式、可取消且具备双倍空间预检的转换流程；默认继续不转换；
- 历史签名AI/核心升级与回退期间的数据库兼容矩阵。

这些门禁完成前，AI进程和数据库不得加入正式安装包。
