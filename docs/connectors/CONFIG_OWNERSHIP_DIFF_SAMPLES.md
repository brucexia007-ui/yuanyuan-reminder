# 连接器配置合并与撤销差异样例

更新时间：2026-08-04  
状态：官方配置外形已冻结；只读差异、内部接入与精确撤销事务已实现；正式入口仍关闭

当前官方配置依据、用户级来源选择、事件语义和所有权参数见 `HOOK_CONFIG_FORMATS_2026-08-04.md`。本页继续冻结合并与撤销语义，禁止据此直接修改用户配置。

## 接入前

```text
用户已有配置
├─ 用户Hook A
├─ 用户Hook B
└─ 其他工具配置
```

## 圆圆接入后

```text
用户已有配置（字节语义保持）
├─ 用户Hook A
├─ 用户Hook B
├─ 其他工具配置
└─ 圆圆拥有片段
   ├─ command: <Bridge固定路径>
   └─ args
      ├─ owner_id: yuanyuan-reminder
      ├─ connector_id: <内置实现标识>.<随机稳定UUID>
      ├─ source_instance: <不透明实例ID>
      └─ key_id: <Credential Manager引用>
```

接入操作必须先展示结构化差异并取得用户确认，执行时再次校验摘要，再保存带时间戳备份并原子替换。若无法无损保留未知字段、顺序、换行或注释，停止接入并说明原因，不能重写整个文件。当前 JSON/JSONC 编辑器已能逐字保留旧内容并生成缺失片段；稳定核心内部协调器也已在临时目录中验证两分钟单次确认、执行前重读、同目录备份、文件身份复核、原子替换及失败不改原文。其官方目标封装只接受授权身份或确认令牌，并把全部用户级候选来源一起绑定；它没有 Tauri 命令或设置页入口，所以产品行为仍是零写入。

## 圆圆断开后

```text
用户已有配置
├─ 用户Hook A
├─ 用户Hook B
└─ 其他工具配置
```

撤销只删除 `owner_id + connector_id + source_instance` 精确匹配，且原始节点字节仍等于圆圆规范写入值的 handler。规范单-handler圆圆组可以整组移除；混合组只移除圆圆的规范 handler，保留用户 handler、组、注释和未知字段。若用户给圆圆节点加注释、重新格式化、改字段或复制，即使语义仍相同也停止自动撤销；不得删除同事件上的其他Hook。内部官方断开预览与接入一样只接受已授权身份，确认只接受单次令牌，并重新绑定全部用户级来源。

## 契约测试要求

- 空配置、已有单Hook、已有多Hook、未知字段、注释、重复圆圆片段和用户修改后的冲突；
- 接入执行两次保持幂等；
- 撤销执行两次保持幂等；
- 任一步失败时原文件保持可解析且用户片段不丢失；
- 凭据正文不进入配置、备份、差异、日志或诊断包。

当前 `config_preview` 已覆盖空/非法/超限配置、用户 Hook 共存、未知顶层字段计数、完整/部分集合、事件或字段被修改、同事件多 matcher、重复/意外圆圆 handler、混合 matcher 组，以及 JSON/TOML 输出脱敏。多来源预览还能阻断 Codex 用户层内联/双表示和圆圆条目跨来源冲突，同时允许 Claude 项目级用户 Hook 共存。`config_edit` 的接入与撤销共同覆盖 JSON/JSONC 注释、未知字段、混合用户 Hook、部分安装、幂等、重复键、修改/重复/重格式化冲突和容量，并证明用户字节保持。私有写入协调器覆盖接入/撤销候选的精确备份、单次消费、过期、并发内容变化、同内容换文件、目标占用、错误脱敏与失败不改原文；官方目标封装进一步覆盖路径不可注入、所有用户来源绑定、授权/根目录变化、冲突无令牌、连接—断开—重复断开和容量。私有组合状态机已覆盖配置优先、冲突后显式仅断权、配置失败不自动断权、配置成功后断权重试，以及“权限已撤销但凭据清理/本地维护待完成”的精确分类。需要符号链接创建特权的真实重解析点用例仍作为发布门忽略于普通测试。项目级零写入检查已有产品入口，真实Hook写入的正式产品入口仍未实现。
