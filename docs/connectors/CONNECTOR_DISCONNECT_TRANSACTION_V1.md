# 连接器断开组合事务 v1（内部原型）

日期：2026-08-04  
状态：状态机、故障/恢复矩阵和开发环境交互实验台已实现；无 Tauri command、正式产品入口或真实配置执行

## 1. 两种明确模式

断开不能用一个含糊按钮同时代表“删除 Hook”和“撤销认证权限”。内部协议固定两种需要分别预览和确认的模式：

- `remove_configuration_and_revoke_trust`：默认模式，先精确撤销圆圆配置，成功后立即撤销该身份全部认证权限；
- `revoke_trust_only`：只撤销认证权限，不打开或修改任何 Hook 配置。用于用户配置已改变、路径不安全或用户只想立即断权的场景。

两个生产函数入口都只接受 `connector_id + source_instance`，应用时只接受随机单次令牌；不存在路径参数。令牌两分钟过期、最多16项，绑定模式和完整身份。

## 2. 预览状态

- `ready_for_confirmation`：当前身份活动，所选模式可以执行；
- `configuration_manual_review`：配置不能自动撤销，不签发组合令牌，并明确提示可另行选择“仅撤销信任”；
- `no_change`：仅断权模式下权限已撤销，不签发令牌；若权限已先撤销而配置可能残留，默认模式进入人工复核，因为当前活动密钥引用已不可用于证明旧节点。

所有预览只返回固定枚举、数量和布尔事实，不返回连接器身份、路径、命令、配置正文、摘要、密钥引用或系统错误。

## 3. 应用顺序与结果

默认模式严格执行：

1. 单次消费组合令牌；
2. 由官方配置事务重新验证授权、官方根目录、全部用户级来源、节点规范字节和底层确认；
3. 配置备份与原子替换成功后，才调用信任重置；
4. 信任库先撤销权限，再清理精确凭据目标，并重新检查活动状态。

固定结果包括：

- `disconnected`：配置阶段（若需要）完成，认证权限已验证撤销；
- `configuration_removal_failed_trust_not_attempted`：配置阶段失败，组合流程没有擅自断权；用户可以重新预览，或明确改选仅断权；
- `trust_revocation_failed_still_active`：配置已撤销，但权限仍活动，需要仅断权重试；
- `trust_revocation_unverified`：无法确认权限状态，不能宣称成功；
- `disconnected_credential_cleanup_pending`：权限已验证撤销，但一个或多个孤立凭据待清理；不得显示为仍有权限；
- `disconnected_local_maintenance_pending`：权限已验证撤销，但本地DACL等后置维护待重试；不冒充凭据清理错误；
- `disconnected_credential_cleanup_and_local_maintenance_pending`：权限已验证撤销，但精确凭据清理与本地DACL维护均待完成；两项事实同时返回；
- `no_change`：所选模式已满足。

结果分别返回配置是否写入/备份、删除数量、是否尝试断权、权限是否已验证撤销、凭据清理或本地维护是否待完成、是否需要重试，以及固定恢复动作。恢复动作区分重新预览、仅重试断权、重新检查权限、重试凭据清理、重试本地维护和两项维护一起重试；来源任务行为始终不被改变。

撤权后维护使用独立确认事务，不复用含糊的“再次断开”：预览再次验证权限已撤销，只接受固定恢复动作与完整连接器身份；确认仍为两分钟单次令牌且与断开令牌共享16项总容量。应用只处理信任库证明已经撤销、属于该实例且尚未记录清理完成的精确凭据ID，每次最多256项；成功或本来已不存在的凭据会记录清理完成，失败项留待下一次重试。维护事务不读取或修改Hook、不重新授权、不扫描Credential Manager，也不接受路径。

## 4. 当前证据

内部夹具覆盖：

1. 配置撤销严格先于信任重置；
2. 配置冲突不签发组合令牌，但显式仅断权可以执行；
3. 配置应用失败不调用信任重置；
4. 配置成功、权限仍活动时返回可重试的分阶段结果，随后仅断权成功；
5. 权限已撤销但凭据清理失败不会误报为仍活动；
6. 权限已撤销但本地维护失败与状态不可确认分别分类；
7. 已撤销幂等、令牌过期/重放、内部配置令牌清理和16项容量；
8. 序列化预览不包含身份或路径，生产入口函数签名不接受路径。
9. 撤权后维护令牌不能跨断开入口使用，活动权限、错误恢复动作、过期与重放全部关闭失败；凭据、本地DACL及两者同时失败分别分类。

底层真实信任管理器已有独立测试证明：`reset_trust`先提交SQLite权限撤销，再尝试凭据删除；删除失败最多留下没有认证权限的孤立凭据。信任库为撤销凭据保存独立清理完成标记，夹具已证明失败后可有界重试、成功推进且重复调用幂等。

开发环境专用实验台已覆盖两种模式、冲突退路、按序执行、权限已撤销后的维护提示和权限仍活动的强警告；默认执行能力为关闭。自动交互测试覆盖显式勾选、模式变化清除旧确认、固定恢复动作、读屏角色和输出脱敏；1100×800与390×620浏览器实拍无横向溢出，控制台无warning/error。实验台使用开发环境动态加载，发布边界脚本禁止其标识、文案和样式进入正式`dist`。
