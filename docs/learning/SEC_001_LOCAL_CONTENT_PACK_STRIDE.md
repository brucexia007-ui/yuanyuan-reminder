# SEC-001 本地内容包 STRIDE 与安全夹具

状态：安全边界已冻结；内容层 001—011 已由 pre-GEN 纯解析器执行，token/安装语义仍待 GEN 后闭环<br>
日期：2026-08-19<br>
适用范围：阶段 1 本地 JSON/CSV 内容包，不适用于远程源、市场、插件或可执行内容

## 信任边界

1. 用户只能通过系统文件选择器授予一次本地普通文件读取能力；WebView 不接收或持久化原始路径。
2. 文件在解析前先检查类型、普通文件属性和字节预算；解析过程不得执行脚本、宏、公式、URL、命令、模板或内容包声明的扩展。
3. JSON/CSV 进入严格、版本化、拒绝未知字段的 DTO；Unicode 控制符、双向覆盖符、公式前缀和非规范标识符失败关闭。
4. 预览只生成有界、短时、单次使用的随机 token，不产生用户可见数据库写入。确认命令只接受 token，不接受路径或任意 SQL/文件参数。
5. 校验通过的数据写入同一应用数据根内的 staging 数据库；完成一致性检查和落盘后才原子切换可见版本。失败、取消、崩溃均保留旧版本与旧进度。
6. 内容资源仅允许包内规范相对引用；绝对路径、父目录穿越、重解析点、网络 URL 和 `data:` 资源均拒绝。
7. Tauri capability 保持现有最小权限：无 shell、HTTP、任意文件系统或进程执行权限。内容包不得增加 command、permission 或 CSP 来源。
8. 错误 DTO 只返回包内逻辑文件名、行/字段、稳定错误码与可行动建议；不返回用户绝对路径、数据库路径、原始机密行或堆栈。

## 夹具与执行门

夹具清单位于 `src-tauri/tests/fixtures/learning-content-security/manifest.json`，全部是合成数据。清单绑定每个文件 SHA-256、预期结果、STRIDE 类别、控制和责任角色。`learning:security:fixture:verify` 负责证明夹具集合、预算和哈希未漂移。

经用户授权的 pre-GEN 纯解析 spike 已把同一清单接入独立 Rust parser/validator：SEC-FIX-001 接受，002 的声明身份不一致被拒绝，003—010 的结构/Unicode/路径与资源声明/重复/深度/畸形/公式输入失败关闭，011 的文件与卡数预算分别拒绝。普通非符号链接文件读取、输入预检、跨块 UTF-8、语法、解码、结构、逐卡校验和流式最终化现分别按 4 MiB、16,384 个 JSON 值或 256 张卡提供协作取消/进度检查点；serde_json/csv 解码输入和单卡字符串扫描、Unicode 规范化输入、CSV 分隔符/可选字段扫描、复制、哈希、规范 JSON 序列化另分别按 16 KiB 轻量探针检查取消，不增加 UI 进度事件。正式 JSON 九阶段、CSV 八阶段均返回明确 `Cancelled` 且不产生部分 `ParsedPack`；25 项库测试还证明 JSON 可在结构可见前取消、CSV 与单张超长 JSON/CSV 卡均可在完成任何卡片前取消，并覆盖 NFC/NFKC 与 CSV 尾项路径。独立隔离门另以 6 项正反向测试和当前 `cargo metadata`/源码/配置/产物扫描证明 spike 不属于默认 workspace、不被其他 workspace 包依赖、不注册 Tauri 能力、不含 SQLite/网络/子进程启动能力且不可发布。正式 20,000 卡 JSON/CSV 夹具同时达到 26,020,105/26,120,061 bytes，并在未放宽候选门时通过 30/30 release 样本。操作系统阻塞在单次 ≤4 MiB 读取调用内仍无即时检查点；上述结果也仍不是取消零数据库写入证据。012/013 描述文件不会被解析器误当内容包接受，但纯解析器没有文件替换 token、数据库或 staging，因此不能证明 `reject_second_use` 或 `old_state_unchanged`。

执行细节和正式性能报告见 `PRE_GEN_PURE_PARSER_SPIKE.md`。PACK-001 仍必须在 GEN-000 冻结后复用这些内容层断言，并补齐 Tauri 后台调度与 UI 响应、preview token 单次消费/TTL、取消零写入、失败/崩溃无半安装和旧状态不变。完成前不得把 SEC-001 标记为全部完成。

## 停止条件与明确 No-Go

- 若需求要求执行内容包代码、联网拉资源或开放任意路径权限，停止 PACK-001 并重新评审。
- 若 25 MiB/20,000 卡预算无法在桌面基线内完成，先调整格式或分包设计；不得静默提高预算。
- 若失败注入后旧包、旧进度或提醒库不能对账，停止后续包管理开发。
- 本文不批准公开词库、个人词库进入通用分支，也不批准远程更新、签名市场或第二学科发布。
