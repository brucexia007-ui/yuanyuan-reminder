# Learning Preview 内容来源与权利边界

日期：2026-08-10<br>
结论：当前没有获准随产品再分发的考研英语内容包；生产能力只接受用户导入

## 当前裁决

| 来源 | 当前用途 | 是否进入产品包 | 裁决 |
| --- | --- | --- | --- |
| 用户自己的 CSV | 用户主动导入的词头、释义和可选进度提示 | 否 | 允许；产品不上传、不再许可、不改标为官方内容 |
| 圆圆原生 JSON | 用户自己的完整学习数据备份/恢复 | 否 | 允许；只在用户选择的本地文件中读写 |
| 浏览器演示词 | UI 自动化与视觉验收的内存夹具 | 否 | 只允许开发环境；刷新重置，不写本机数据库 |
| ECDICT 等社区词典 | 未来候选富化来源 | 否 | 未完成逐字段来源、再分发和派生数据库权利审查，不进入构建输入 |
| Tatoeba | 未来例句候选 | 否 | MVP 本身排除例句；即使以后使用也需署名链与语言复核 |
| 真题/商业词表/背词应用导出 | 可能由用户个人合法持有 | 否 | 不抓取、不打包、不兼容私有格式；用户应确认个人使用权 |

“开源可获取”不等于“可以把选词、中文义项和例句作为考研教学包重新分发”。因此本轮不采纳“完全取消人工复核”：自动化可以完成去重、规范化、哈希、字段校验和异常报告，但不能替代权利判断与中文义项质量责任。

## 用户导入边界

通用 CSV 支持以下内容字段：

- 必需：`headword`、`meanings_zh`；
- 可选：音标、词性、词族、`progress_hint`、来源标签；
- `progress_hint` 只能确定性映射为新卡/学习中/相对稳定的初始队列，不冒充其他产品算法的精确进度；
- 导入前只做内存预览，用户确认后才在独立学习库内原子写入；
- 错误日志只记录错误类别和行号，不记录用户词条正文；
- 产品不联网核验、不上传、不向其他用户分发导入内容。

原生 JSON 是圆圆自己的完整可移植格式，版本标识为 `yuanyuan.learning.export`、schema v1。未知字段、未来版本、引用不完整、哈希/数量/长度超限和双向控制字符都会拒绝。

## 未来内置研究包的最低证据

只有以下项目全部具名签署，LRN-001/002 才能从“阻断”变为“通过”：

1. 每个输入文件、字段和派生结果的来源、版本、URL、许可证、归属、notice 与 SHA-256；
2. 考研语料的取得方式、允许用途、可否再分发和可否生成派生词频/义项；
3. 英语一/二公共核心、中频候选带、lemma 归并、熟词僻义和 `sense_basis` 的可重复规则；
4. 100% 自动结构质量门及异常清单；
5. 覆盖词性和频率分层的语言抽样方案、样本量、置信口径和具名语言确认；
6. 生成产物与输入的确定性哈希、许可证清单、SBOM 和安装/卸载边界。

缺少任何一项时，只能继续“用户导入优先”的 MVP，不能用通用词典或开源仓库名称替代“考研词包已审核”的结论。
