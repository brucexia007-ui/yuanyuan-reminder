# 圆圆小黑板英语学习升级方案与开发合同

日期：2026-08-11
适用版本：圆圆提醒 v1.4.0 的 Learning Preview；`personal-kajweb` 个人构建额外内置 KaoYan_2 词库
发布边界：默认稳定版继续关闭学习功能；个人构建仅供本机使用，不上传或再分发词库

## 1. 产品结论

学习仍是 1—5 张、可随时退出的碎片化微会话，但主交互从“翻卡后自我评分”升级为“圆圆拉出小黑板进行中文释义选择”。圆圆不是聊天机器人或系统弹窗：它负责开场、守候、用绿色勾/红色叉作非语言反馈，并在结束后收起黑板。

一次最小闭环为：

```text
手动开始或低频安全邀请
  → 后端挑选到期词/受额度限制的新词
  → 后端生成 2—4 个消歧后的中文选项
  → 用户选择
  → 后端判定并原子记录
  → 对/错分别映射为 FSRS Good/Again
  → 本轮错题末尾再看一次（回看不重复调度）
  → 完成或随时退出
  → 错题/学习过的词可在学习菜单检索
```

若同一词包不足以生成至少两个安全选项，必须降级为主动回忆翻面与“忘了/模糊/记得”，不得用明显错误或含义近似的干扰项凑数。

## 2. 已有项目基础

- Windows Tauri 2 + React/TypeScript + Rust/SQLite，离线、本地优先。
- 学习功能由前后端 feature gate 隔离，默认发行构建不包含学习页面和命令。
- 学习库与提醒主库分离；已有 CSV/原生 JSON 导入、导出、清空进度和彻底删除。
- 已接入 `fsrs` 6.6.1，默认目标保持率 0.9，不训练个人参数。
- 已有手动模式与明确选择的低频自动邀请；锁屏、演示、全屏、专注/安静模式或未知状态均抑制。
- 普通提醒、喝水、活动、专注、任务守望等高优先级事件可撤下邀请或中断学习；已提交答案保留，未答题不计入。
- 个人构建已固定并校验 `kajweb/dict` 的 KaoYan_2 源文件，生成 4533 张本地卡片；与稳定版使用不同应用标识和数据目录。

## 3. 交互与状态

### 小黑板

- 黑板显示英文词头、音标、词性及编号选项；提交前不暴露答案。
- 首个选项自动获得键盘焦点，数字键 1—4 可作答，Esc 随时收起。
- 提交后锁定所有选项，正确项始终明确标出；答错时同时标出用户选择并显示正确释义。
- 圆圆使用现有合法精灵动画；绿色 `✓` 与红色 `×` 是可见反馈道具，不可点击，也不是评分入口。
- 正确/错误必须有文字与样式双重表达，不仅依赖颜色；减少动态设置下禁用位移动画。
- 结果保持在屏幕上，只有用户点击“下一题/看看本次结果”才继续，不自动跳题。

### 错题回看

- 每张原始卡最多进入本轮回看队列一次。
- 原始答题立即更新一次 FSRS；正确映射 `Good`，错误映射 `Again`。
- 回看答案只写答题记录并完成队列项，不再次更新 FSRS，也不增加原计划完成数。
- 会话只有在原计划卡和回看队列都完成后结束。

### 学习记录

- 学习首页提供“查看错题”和“学习过的词”入口。
- 支持错题、学习过、全部词汇三个筛选，英文/中文搜索及每页 20 条分页。
- 每项显示词头、释义、阶段、答对/答错次数及最近错题日期。
- 查询在 SQLite 中完成聚合、筛选和分页，不把 4533 张卡全部加载进界面。

## 4. 数据和 API 合同

学习数据库 schema v3 新增：

- `learning_question_attempts`：保存问题、用户选项、正确选项、结果、是否回看、映射评分、耗时和时间；`client_answer_id` 唯一以支持幂等重试。
- `learning_remediation_queue`：保存本轮错题回看位置和完成状态；每个会话/卡片唯一。

核心命令：

- `get_current_learning_question(session_id)`：只返回作答所需内容；题目和选项 ID 由后端稳定生成。
- `answer_learning_question(session_id, question_id, selected_option_id, client_answer_id, response_ms)`：后端验证题目、判定、排程和记录，单事务提交。
- `list_learning_records(filter, query, page, page_size)`：本地分页查询错题与学习记录。

客户端不得从卡片完整释义自行判断答案。答题耗时只作本地记录，第一版不参与 FSRS 评分。

原生 JSON 备份兼容旧 schema v1 文件，并在新导出中包含答题记录和未完成回看队列；恢复时执行引用、哈希、枚举、时间和唯一性校验。

## 5. 调度与开源吸纳边界

- 继续使用 Open Spaced Repetition 的 `fsrs` 6.6.1（BSD-3-Clause），仅吸纳调度库，不引入账号、云服务、训练器或遥测。
- 释义选择题的干扰项从同一已就绪词包中确定性生成，优先同词性与邻近频率，并剔除完全相同、包含关系明显或中文 token 高度重合的候选。
- 不接入需要联网的题库/AI，不让 AI 决定答题正确性或调度。
- `kajweb/dict` 内容只进入用户明确要求的个人本机构建；当前没有再分发批准，因此不能进入稳定版、仓库提交或 GitHub 产物。

## 6. MVP 纳入与排除

纳入：小黑板选择题、圆圆真实动画反馈、结果停留、键盘操作、错题本轮回看、错题/已学查询、FSRS、本地备份恢复、手动与已有安全自动触发、优先级抢占。

排除：例句、发音音频、拼写/听写、聊天式讲解、AI 生成释义、联网同步、排行榜、响应速度评分、用户自定义干扰项、自动连续播放、把“相对稳定”宣传为掌握或提分。

## 7. 验收标准

1. 题目提交前无法从前端 DTO 得到正确答案；伪造 question/option/client ID 均拒绝。
2. 原始答题只生成一条 FSRS 复习日志；答错回看和网络式重复提交均不重复调度。
3. 答错后可见所选错误项、正确项、正确释义、红色按钮反馈和圆圆动画；答对对应绿色反馈。
4. 360×560 到 480×760 无横向溢出，键盘和减少动态可用。
5. 4533 词包下出题与记录查询不做全表传输，页面操作期间不阻塞文件选择或导出取消。
6. 学习过程中高优先级提醒到达时立即中断表达；已答题提交保留，未答题不写记录。
7. 默认关闭构建仍通过学习边界验证；个人构建通过固定源哈希、4533 卡片数、Rust/前端测试和安装启动验证。

## 8. 分阶段顺序

- P0：客观题后端合同、原子记录、FSRS 映射、回看队列、黑板 UI、错题/已学查询。
- P0 验收：自动化测试、真实尺寸视觉 E2E、默认关闭边界、个人词包和安装包验证。
- P1：根据个人使用数据调整干扰项质量、黑板动效节奏和错题入口，不改变调度语义。
- P2：只有在内容权利、无障碍、Windows 防打扰矩阵和用户研究通过后，才讨论稳定版入口或更多学习内容。
