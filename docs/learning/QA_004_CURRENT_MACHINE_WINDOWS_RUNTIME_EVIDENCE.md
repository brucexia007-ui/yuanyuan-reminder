报告中的第 8 轮可访问名称同时出现答错反馈与宠物按按钮状态，支持以下诊断推断：自动宠物交互在提醒出现前提交了答案，使“未作答题目”测试前提失效；同一首次运行中的另外三个 8 秒相位样本均通过。该失败不是延迟阈值放宽后取得的通过：失败报告继续保留，随后只按完全相同的 20 样本、30 秒受控退出和原阈值复验一次，复验 20/20 通过。若后续再次出现同类失败，应修正夹具以禁用该自动答题碰撞，而不是继续重复运行直至偶然通过。

## 4. 观察到的产品状态

- 可访问性：360×560、390×620、480×760 学习页和 520×420 小黑板均在当前工作区内；标准、程序化减少动态、程序化强制颜色三种模式可由 Windows UI Automation 识别，首个答案可聚焦。
- 睡眠/唤醒：真实原生菜单被打开并检查；共用菜单处理器使活动学习会话从 `active` 变为 `paused/preempted_high_priority`，只写入一次 interrupted 事件且零答案写入；唤醒后保持暂停和可恢复，小黑板不自动重开。
- 强提醒：20 个隔离数据根覆盖 2/5/8/11/14 秒五种到期相位；接受报告中会话、题目和 headword 均保持不变，零答案写入，SQLite 暂停先于 UI 让位，受控退出和测试根清理均通过。
- 11 张捕获图已逐张视觉检查：三个面板尺寸均有可见纵向滚动且无横向溢出，三种小黑板模式内容完整，睡眠/唤醒宠物帧和两次原生菜单无空白、文字截断或异常遮挡。该辅助检查不计作具名人工 Windows QA。

## 5. 限制

这些是隔离的未签名 runtime-QA 二进制，不是 Stable、Learning Preview 安装包或签名候选。当前电脑复验没有覆盖 100/125/200% DPI、多显示器/负坐标、物理右键与 OS 级菜单选择、完整物理键盘会话、Narrator、Windows 设置实际切换、锁屏/全屏系统适宜性或全优先级真实桌面时序。程序化减少动态/强制颜色和共享菜单处理器触发不能替代具名人工 Windows QA。
