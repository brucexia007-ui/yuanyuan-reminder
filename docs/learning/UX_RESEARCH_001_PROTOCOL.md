## 研究问题

普通非技术用户能否从一份零散工作笔记出发，在不上传原始内容的情况下制作 10—20 张可导入学习卡？需要验证：准备成本、字段理解、错误恢复、放弃点，以及真正必要的最小编辑能力。

## 执行目标与产品边界

当前 Learning Preview 只支持既有英语词表 CSV/原生备份，不具备本研究需要的通用字段映射和内容库回程。它不能执行下述任务，也不能被当作通用内容包 UX 证据。

本研究改用 `ux-research-001/prototype.html` 独立交互草图。它只在页面内存中模拟“字段映射 → 抽样预览 → 导入 → 学习 → 内容库”，没有文件读取、持久化、网络、Tauri、数据库或真实导入能力；刷新即清空。研究结果只作为 GEN-000 的产品输入，不证明 PACK-001—004 已实现。开始真实招募前必须先由 Product Research 完成至少一场内部试跑，确认任务说明和固定记录代码可用。

## 招募与停止条件

- 5—8 名参与者；至少 4 名不以软件开发或数据处理为主要工作。
- 使用研究方提供的合成笔记，或参与者在本机自行改写且确认无机密的笔记。
- 不收集原始工作内容、屏幕录制、真实文件、绝对路径、账号、客户/项目名称或个人身份字段。
- 若任务只有上传机密材料才能继续，立即停止该场次并改用合成笔记；不让参与者“先脱敏再上传”。

## 任务材料

受控执行包位于 `docs/learning/ux-research-001/`。每位参与者随机使用 A—D 中一份 15 条合成笔记和 `card-builder-template.csv`，覆盖：

- 一行一个事实；
- 一行含两个可拆分事实；
- 缺少答案的模糊记录；
- 重复/近重复记录；
- 含逗号、引号、换行、非 ASCII 字符；
- 适合选择题和只适合回忆题的混合内容。

材料只在研究设备本地出现。记录表使用 `templates/session-record.template.json` 的副本，只允许参与者编号 `P01`—`P08`、固定枚举、时间和次数；不得新增原文、姓名、联系方式、文件名或路径字段。执行包的文件清单、LF 规范化 SHA-256 和覆盖标签由 `manifest.json` 冻结。

## 任务流程（45 分钟内）

1. 口头说明本地处理和不收集原文的边界，取得记录匿名指标的同意。
2. 参与者阅读合成笔记，制作 10—20 张卡；主持人不解释字段，除非参与者明确求助。
3. 将卡片 CSV 文本粘贴到研究原型，使用字段映射与抽样预览修复至少一个故意设置的格式问题。
4. 在研究原型内完成模拟导入、开始一轮模拟学习，再返回模拟内容库找到刚才的包；主持人必须明确这不是实际产品写入。
5. 半结构访谈：最不确定字段、最想删除的步骤、遇到错误时预期、是否需要本地极简编辑器。

## 量化记录

| 指标 | 记录规则 |
| --- | --- |
| 准备时间 | 从看到材料到首次选择导入文件 |
| 首次预览成功时间 | 从开始任务到无阻断错误的抽样预览 |
| 总完成时间 | 到成功开始一轮学习 |
| 字段求助次数 | 主持人解释字段含义的次数 |
| 映射错误数 | 预览前后分别记录 |
| 放弃/绕过点 | 步骤编号与匿名原因代码 |
| 修复成功率 | 首次错误后能否在 5 分钟内独立修复 |
| 最小编辑需求 | 无、改一格、增删卡、批量替换、其他（仅摘要） |

不记录卡片原文。问题示例仅标成 `missing_answer`、`duplicate`、`delimiter`、`encoding`、`field_mapping` 等固定代码。

## 通过/处置规则

- 至少 6 人完成，且至少 4 人无需主持人代操作。
- 中位首次预览成功时间不超过 15 分钟。
- 至少 70% 的故意格式问题可在有限错误摘要帮助下独立修复。
- 若 3 人以上要求在导入前改单格或删卡，将“抽样预览中的最小本地编辑”进入阶段 2 候选；不直接扩大阶段 1。
- 若主要失败来自 CSV 概念而非产品映射，PACK-002 必须提供更明确的示例下载与字段映射，不以文档培训替代。

## 匿名汇总模板

最终按 `ux-research-001/templates/summary.template.md` 提交：参与人数与背景分组、各时间指标的中位数/P90、固定错误代码计数、完成率、三条以内主题代码摘要、阶段 1 必改项、阶段 2 候选和明确未收集项。原始主持记录在汇总后删除。
