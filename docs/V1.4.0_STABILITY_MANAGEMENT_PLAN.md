# 圆圆提醒 v1.4.0 稳定与管理版方案

## 目标

在保持完全离线、无需 Codex 和不清空既有数据的前提下，把圆圆提醒从“可使用”升级为“可长期管理与恢复”的桌面工具。

## 1. 模块故障隔离

- 今日提醒、设置、专注和互动统计分别加载、分别保存错误状态。
- 任一模块失败时，其余模块仍显示最新成功数据。
- 失败模块提供明确原因与“重新加载”，不得再用一个错误覆盖整个面板。
- 后端事件只刷新受影响模块；跨零点刷新今日提醒与互动统计。

验收：模拟互动统计失败时，今日待办、喝水计数、专注和设置仍可使用；恢复后可单独重试互动统计。

## 2. 提醒全生命周期管理

- 新增“管理”页面，列出所有未归档提醒。
- 用户提醒支持编辑、启用、停用和删除。
- 删除采用软删除，历史记录和既有处理结果继续保留。
- 编辑、停用或删除时，当前未处理实例自动结束，并记录明确原因。
- 默认喝水和久坐活动属于系统提醒，只能从设置页调整，不能误删。
- 重复规则支持自选星期，并允许调整生效时间段。

验收：创建提醒后可编辑并重新计算下次时间；停用后不再触发；重新启用后恢复排程；删除后管理页消失且历史仍可查询。

## 3. 自动备份与安全恢复

- 数据库每日首次启动自动备份一次，保留最近 14 份自动备份。
- 设置页支持立即备份、查看备份列表和恢复指定备份。
- 恢复前自动创建安全备份。
- 恢复文件必须通过 SQLite 完整性校验，文件名必须限制在应用备份目录内。
- 恢复完成后重新加载设置、提醒、专注、互动和活动累计状态。

验收：备份后修改数据，再恢复备份，数据回到备份状态；损坏文件和路径穿越请求被拒绝；恢复失败时原数据库保持可用。

## 4. 多档稍后与错过提醒

- 面板和圆圆大提醒均支持 5、10、30、60 分钟稍后提醒。
- 设置中新增错过提醒策略：全部补发，或超过宽限时间自动跳过。
- 宽限时间支持 15、30、60、120、240 分钟。
- 自动跳过写入历史并标明“错过后自动跳过”。
- 正常 15 秒调度延迟不能被误判为错过。

验收：选择 30 分钟后，实例精确进入 30 分钟稍后状态；超过宽限的实例不弹出并进入历史；宽限内实例仍正常提醒。

## 5. 自动化 E2E 与质量门槛

- 前端覆盖“局部失败不影响其他模块”和“创建→编辑→停用→启用→删除”界面流程。
- 后端覆盖完整提醒流程、系统提醒保护、自动跳过、备份恢复和旧数据库迁移。
- 每次发布必须通过：
  - `npm.cmd run verify`
  - `cargo test`
  - 浏览器面板可见 E2E
  - `npm.cmd run tauri build`
- 使用 v1.3.2 真实数据库副本验证迁移、备份和恢复，不修改原始用户数据进行破坏性测试。

## 数据模型

### reminders 新字段

- `archived_at TEXT NULL`：软删除时间。
- `system_kind TEXT NULL`：`water` 或 `activity`，用于保护系统提醒。

### occurrences 新字段

- `resolution_reason TEXT NULL`：记录 `manual`、`missed`、`reminder-edited`、`reminder-disabled`、`reminder-deleted` 等结束原因。

### settings 新字段

- `missedReminderPolicy`: `notify` 或 `skipOld`。
- `missedReminderGraceMinutes`: 15–240。
