# yuanyuan-protocol

圆圆任务守望的版本化本地协议 crate。

当前职责：

- 定义任务事件协议 v1；
- 定义任务状态、证据类型、证据等级和终态语义；
- 定义注册式返回动作，不接受任意 URI 或命令；
- 在数据进入 Bridge、稳定核心或持久化之前执行共享边界校验；
- 通过无 Tauri 依赖的测试固定兼容和降级行为。

当前非职责：

- 不连接命名管道；
- 不保存数据库；
- 不访问网络或 Provider；
- 不选择宠物动画和道具；
- 不解析 Codex、Claude Code 等来源的原始 Hook 载荷。

所有外部来源必须先由各自连接器转换成协议事件。协议新增字段默认保持前向兼容；修改已有字段语义、状态或终态规则必须升级协议版本并增加兼容夹具。
