# yuanyuan-connectors

圆圆任务守望的来源适配层。目前只实现离线、保守的 Codex `notify`/Hooks 与 Claude Code Hooks 事件转换，不安装或修改任何真实 Hook。

安全边界：

- 输入上限 64 KiB；
- 不保留提示词、模型回复、工具输入输出、终端记录或原始工作目录；
- 外部任务与会话标识只以 SHA-256 派生的不透明标识进入统一协议；
- 未知来源版本不能生成成功、失败或取消等终态断言；
- `Stop`、`StopFailure` 和单次工具失败不等同于任务失败或成功；
- Hook 的固定契约是空标准输出、退出码 0；解析和投递失败不得改变源工具决策。

`tests/fixtures` 中当前全部是依据冻结设计制作的合成契约样本，不是真实工具录制。它们用于先固定圆圆自己的安全行为，不能替代目标版本的官方文档复核、脱敏真实载荷和实机非干预测试。
